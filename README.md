# MAESTRO grpc-service-template

Репозиторий с шаблоном grpc-сервиса MAESTRO.
Используется для создания новых сервисов.

## Usage 
Run
```bash
uv pip install copier
copier copy https://github.com/AIRI-MAESTRO/maestro-grpc-service-template.git /path/to/your/project
# answer to questions to fill arguments
```
## Passing arguments
```bash
copier copy https://github.com/AIRI-MAESTRO/maestro-grpc-service-template.git /path/to/your/project --data=service_name=universal-everything-maker
```
